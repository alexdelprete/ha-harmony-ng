# Release v0.1.7

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-harmony-ng/v0.1.7/total?style=for-the-badge)](https://github.com/alexdelprete/ha-harmony-ng/releases/tag/v0.1.7)

**Release Date:** 2026-11-09

**Type:** Patch release - PowerOff is no longer listed twice.

## What's Changed

### Fixed

- PowerOff listed twice: the Hub lists PowerOff with the activities, so the activity select
  offered it twice, the remote's activity list included it, the options offered it as the
  default activity, and a "Start PowerOff" button duplicated the Power off button. The Hub's
  entry is now left out, as the core integration does, and the extra button is removed on
  upgrade. The remote still reports PowerOff as its current activity while the Hub is off.
