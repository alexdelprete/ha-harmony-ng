# Release v0.1.5

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-harmony-ng/v0.1.5/total?style=for-the-badge)](https://github.com/alexdelprete/ha-harmony-ng/releases/tag/v0.1.5)

**Release Date:** 2026-11-09

**Type:** Patch release - the infrared receiver retries a capture start that failed.

## What's Changed

### Fixed

- Infrared receiver: a request to start capture that failed was not tried again, so capture
  stayed off until the Hub happened to send another status. Over MQTT, a request sent the moment
  the Hub comes back online can be lost, because the Hub reports online before it listens for
  commands. A failed request is now tried again every 30 seconds while the Hub does not report
  capture on, and the failure is logged once.

### Changed

- The repository's copy of the firmware specification matches the firmware again: the
  `remote_rf` button source, the remote renames, and the Bluetooth and RF status as the firmware
  writes them.

## Upgrade notes

- **Battery voltage shown as "4150.00 mV":** a battery voltage sensor kept in mV shows two
  decimals because of a Home Assistant bug
  ([home-assistant/core#191354](https://github.com/home-assistant/core/issues/191354)). Set the
  sensor's unit to V in its settings to read "4.15 V".
