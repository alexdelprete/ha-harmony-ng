# Release v0.1.1

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-harmony-ng/v0.1.1/total?style=for-the-badge)](https://github.com/alexdelprete/ha-harmony-ng/releases/tag/v0.1.1)

**Release Date:** 2026-11-06

**Type:** Patch release - Readable brand icon, brand images to the Home Assistant specification.

## What's Changed

### Fixed

- Brand icon: the square icon carried the full `harmony·ng` wordmark, which shrank to letters about
  10 pixels high on the discovery card and in integration lists. It now uses a compact `h·ng` mark
  in the same typeface with the honey dot. The wide wordmark stays as the logo on the integration
  page.
- Brand images follow the brands image specification: trimmed to the subject, logos at the
  preferred 256 and 512 pixel heights, icons at 256 and 512 pixels, interlaced and losslessly
  optimized.

No code changes.
