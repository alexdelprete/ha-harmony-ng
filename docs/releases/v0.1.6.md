# Release v0.1.6

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-harmony-ng/v0.1.6/total?style=for-the-badge)](https://github.com/alexdelprete/ha-harmony-ng/releases/tag/v0.1.6)

**Release Date:** 2026-11-09

**Type:** Patch release - the remote keeps its model while the Hub briefly does not know it.

## What's Changed

### Fixed

- Remote model: after the Hub's RF service restarts, some firmware reports the remote's model as
  unknown until the remote reboots, and the integration cleared the device's model and reset its
  default name to "Harmony remote". The model the Hub reported before for the same remote is now
  kept, also when Home Assistant starts while the Hub does not know it yet. Another remote has
  another unit id and does not inherit it.
