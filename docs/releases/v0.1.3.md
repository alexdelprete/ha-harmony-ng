# Release v0.1.3

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-harmony-ng/v0.1.3/total?style=for-the-badge)](https://github.com/alexdelprete/ha-harmony-ng/releases/tag/v0.1.3)

**Release Date:** 2026-11-07

**Type:** Patch release - Bluetooth hosts shown connected again, a firmware update check that
recovers on its own, the remote's last battery report, and a stable last boot time.

## What's Changed

### Added

- Per remote, a "Last battery report" sensor: when the remote last reported its battery. A
  battery reading the Hub never received is shown as unknown, whatever placeholder numbers it
  carries.
- Last boot uses the boot time the Hub reports. Over MQTT, a status the Hub republishes (once its
  clock is set, or after a configuration change) reaches Home Assistant at once instead of at the
  next reconnect.

### Fixed

- Bluetooth hosts always showed disconnected and the Bluetooth stack not running, while the Hub
  was connected to them. The Hub forwards its Bluetooth daemon's status file, which flags each
  host on its own; the integration also required an overall flag that the file does not have.
- Firmware update entity: a failed release check stayed unknown for a day, until the next daily
  check. Right after the Hub boots, the check can fail before the Hub reaches the internet. A
  failed check is now retried after 15 minutes, the check also runs whenever the Hub reconnects,
  and a failure is logged once.
- Last boot crept forward with every event the Hub sent. It is now taken from the Hub, or
  computed once per connection on firmware that does not report it.

### Changed

- The remote's battery voltage is shown in volts with two decimals ("3.70 V"). In a locale that
  writes a dot as the thousands separator, "3701 mV" read as "3.701 mV".
- The Hub's Busy sensor reads "Busy" or "Idle" instead of "Running" or "Not running".

## Upgrade notes

- **Battery voltage unit:** Home Assistant keeps the unit of an existing sensor, so an existing
  battery voltage sensor stays in mV. To switch it, open the sensor's settings and choose V. New
  installs get volts.
- **Firmware:** the last battery report, the Hub's boot time and the battery kept across a Hub
  restart need harmony-ng changes that are not in an upstream release yet. On older firmware these
  keep their previous behaviour; nothing breaks.
